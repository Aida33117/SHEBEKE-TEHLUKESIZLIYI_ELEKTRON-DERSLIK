9.1. Firewall – şəbəkələrarası ekranlaşdırmanın əsas mahiyyəti və vəzifələri

Firewall (şəbəkələrarası ekran) şəbəkə trafikini əvvəlcədən müəyyən edilmiş təhlükəsizlik siyasətinə əsasən yoxlayan və ötürülməsinə icazə verən, bloklayan və ya qeydə alan aparat-proqram vasitəsidir. O, daxili şəbəkə ilə etibarsız xarici şəbəkə arasında nəzarət nöqtəsi yaradır. Firewall antivirusun əvəzi deyil: əsas işi bağlantı və trafik siyasətini tətbiq etməkdir.

Inbound traffic

Daxili resurslara doğru gələn trafik. Məsələn, internet istifadəçisinin DMZ-dəki veb serverə HTTPS sorğusu.

Outbound traffic

Daxili şəbəkədən xaricə gedən trafik. Məsələn, tələbə kompüterinin veb səhifəyə müraciəti.

Trusted / Untrusted

Etibar səviyyəsi siyasətlə müəyyən edilən şəbəkələr. Daxili şəbəkə avtomatik olaraq tam etibarlı sayılmamalıdır.

DMZ

İctimai xidmətlərin yerləşdirildiyi ayrıca perimetr zonasıdır. Veb serverdən daxili verilənlər bazasına sərbəst giriş verilməməlidir.

Firewall aktivdir: siyasətə uyğun olmayan trafik bloklanır.

Default Deny — ayrıca icazə verilməyən trafik bloklanır. Default Allow — ayrıca bloklanmayan trafikə icazə verilir. Təhlükəsizlik baxımından, əsaslandırılmış istisnalarla Default Deny yanaşması daha təhlükəsizdir.

Router və Firewall fərqi

Router əsasən şəbəkələr arasında marşrut seçir. Firewall isə təhlükəsizlik siyasətinə əsasən trafiki qiymətləndirir. Müasir router-lərdə firewall funksiyaları ola bilər, lakin bu iki anlayış eyni deyil.

9.2. Firewall – əsas konfiqurasiya və işləmə mexanizmi

Firewall konfiqurasiyası interfeyslərin, IP ünvanlarının, marşrutlaşdırmanın, DNS/DHCP xidmətlərinin və qaydaların düzgün qurulmasından ibarətdir. WAN xarici, LAN daxili, DMZ isə ictimai xidmətlər üçün ayrılmış interfeys/zona ola bilər.

Əsas parametrlər

Parametrləri yoxlamaq üçün düyməni basın.

Stateful inspection bağlantının vəziyyətini izləyir. Məsələn, LAN-dan başladılmış HTTPS bağlantısının cavab paketləri mövcud sessiya kontekstində qəbul edilə bilər. Stateless filtrləmə isə hər paketi ayrıca başlıq məlumatlarına görə qiymətləndirir.

9.4. Proseslərin təftişi və paket filtrləmə

Şəbəkə paketi mənbə və təyinat ünvanı, port, protokol, ölçü və digər başlıq sahələrini daşıyır. Firewall qaydaları adətən yuxarıdan aşağıya yoxlanılır; ilk uyğun gələn qayda qərarı müəyyən edə bilər. Buna görə qayda sırası vacibdir.

9.5. Şəbəkə ünvanlarının translyasiyası (NAT)

NAT (Network Address Translation) paket şəbəkə sərhədindən keçərkən IP ünvanının, bəzi hallarda portun dəyişdirilməsidir. IPv4-də private ünvanlardan istifadə edən daxili qurğuların public ünvana çıxışını təmin etməkdə geniş tətbiq olunur. NAT təhlükəsizlik siyasətini əvəz etmir.

Static NAT

Bir daxili ünvan bir public ünvana daimi uyğunlaşdırılır.

Dynamic NAT

Daxili ünvan hovuzdan müvəqqəti public ünvan alır.

PAT

Bir public IP bir neçə daxili bağlantı üçün fərqli portlarla paylaşılır.

DNAT / Port Forwarding

Xaricdən gələn sorğu müəyyən daxili serverə yönləndirilir.

pfSense ilə praktiki Firewall laboratoriyası

pfSense açıq mənbəli firewall/router platformasıdır. Buradakı tədris simulyatoru real pfSense interfeysi deyil. Real laboratoriya üçün rəsmi ISO/installer, virtual maşın və ən azı iki virtual şəbəkə adapteri istifadə edilir.

  1. VirtualBox-da yeni VM yaradın; uyğun CPU/RAM və disk ayırın.
  2. İki adapter əlavə edin: WAN üçün NAT/bridged seçimini yalnız laboratoriya tələbinə uyğun edin, LAN üçün Internal Network/Host-only seçin.
  3. pfSense-i quraşdırın və WAN/LAN interfeyslərini təyin edin.
  4. LAN interfeysinə, məsələn, 192.168.10.1/24 verin.
  5. LAN hostundan Web Configuration Interface-ə daxil olun.
  6. Firewall > Rules > LAN bölməsində ehtiyac duyulan qaydanı yaradın.
  7. NAT > Outbound və Port Forward bölmələrini öyrənin; port yönləndirməni yalnız zəruri xidmət üçün edin.
  8. Status > System Logs > Firewall bölməsində qayda nəticələrini araşdırın.
  9. Ping, DNS və HTTP/HTTPS bağlantılarını laboratoriya hostları arasında sınaqdan keçirin.
Təhlükəsizlik qeydi

İdarəetmə interfeysini internetə açmayın. Bridged adapter real LAN-a çıxış verə bilər; yeni başlayanlar üçün izolyasiya olunmuş Host-only/Internal Network daha münasibdir. Real sistemlərdə qayda dəyişikliyindən əvvəl konfiqurasiya ehtiyat nüsxəsi alın.

Cisco Packet Tracer ilə ACL və NAT laboratoriyası

Packet Tracer şəbəkə qurğularını vizual şəkildə birləşdirən tədris simulyatorudur. Aşağıdakı IOS nümunələri laboratoriya topologiyasına uyğunlaşdırılmalıdır.

Standard ACL nümunəsi

Router(config)# access-list 10 permit 192.168.10.0 0.0.0.255
Router(config)# interface g0/0
Router(config-if)# ip access-group 10 in

Standard ACL əsasən mənbə IP ünvanına görə filtrləyir. Wildcard mask 0.0.0.255 /24 şəbəkənin host hissəsini uyğunlaşdırır.

Extended ACL nümunəsi

Router(config)# access-list 110 permit tcp 192.168.10.0 0.0.0.255 any eq 443
Router(config)# access-list 110 deny tcp 192.168.10.0 0.0.0.255 any eq 22
Router(config)# access-list 110 permit udp 192.168.10.0 0.0.0.255 any eq 53
Router(config)# interface g0/0
Router(config-if)# ip access-group 110 in

Extended ACL mənbə, təyinat, protokol və portu yoxlaya bilər. Qayda sırası və sonda gizli deny any davranışı nəzərə alınmalıdır.

PAT üçün nümunə skelet

Router(config)# access-list 1 permit 192.168.10.0 0.0.0.255
Router(config)# interface g0/0
Router(config-if)# ip nat inside
Router(config)# interface g0/1
Router(config-if)# ip nat outside
Router(config)# ip nat inside source list 1 interface g0/1 overload

Komandaların interfeys adları və IP ünvanları topologiyadan asılıdır. Əvvəlcə show ip interface brief, show access-lists və show ip nat translations ilə vəziyyəti yoxlayın.

9.7. Praktiki tapşırıq

Tapşırıqları asandan mürəkkəbə doğru yerinə yetirin. Hər tapşırıq üçün topologiyanı, konfiqurasiyanı, sınaq nəticəsini və nəticə/şərhi hesabatda qeyd edin.

  1. Virtual Firewall arxitekturasını qurun: Internet, Router, Firewall, Switch, Server, Client PC, DMZ.
  2. WAN və LAN interfeyslərini konfiqurasiya edin.
  3. HTTP/HTTPS üçün Allow, SSH üçün məhdudlaşdırıcı qayda yaradın.
  4. IP, port və protokol əsasında paket filtrləməni sınaqdan keçirin.
  5. Standard və Extended ACL tətbiq edin.
  6. Static NAT, Dynamic NAT və PAT modelləşdirin.
  7. Wireshark vasitəsilə sintetik və ya laboratoriyada icazəli paketləri analiz edin.
  8. Firewall qaydalarının effektivliyini qiymətləndirin.

İcra mərhələləri

  1. Topologiyanı qurun və qurğuların siyahısını tərtib edin.
  2. WAN, LAN və DMZ interfeyslərini ayırın.
  3. Daxili/xarici IP ünvanlarını və subnet mask-ları təyin edin.
  4. Allow, Block, Reject və Log əməliyyatlarını tətbiq edin.
  5. Source IP, Destination IP, port və protokola əsaslanan ACL qaydaları yaradın.
  6. Static NAT, Dynamic NAT və PAT mexanizmlərini sınaqdan keçirin.
  7. Paketlərin icazəli və bloklanan istiqamətlərini müşahidə edin.
  8. Wireshark-da paketləri və NAT-dan əvvəl/sonra ünvanları müqayisə edin.
  9. pfSense virtual mühitində qaydaları yoxlayın.
  10. Packet Tracer-də ACL/NAT komandalarını tətbiq edin.
  11. Ping və xidmət bağlantısı testləri aparın.
  12. Yekun hesabat hazırlayın və effektivliyi qiymətləndirin.
