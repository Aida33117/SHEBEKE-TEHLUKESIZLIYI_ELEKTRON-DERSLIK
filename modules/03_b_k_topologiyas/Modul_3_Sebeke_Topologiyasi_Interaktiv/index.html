ÖYRƏNMƏ SƏNARİSİ

Universitet kampusunun şəbəkəsi

Təsəvvür edin ki, universitetin üç ayrı korpusu var. Hər korpus üç mərtəbədən ibarətdir. Rektorluq, fakültələr, laboratoriyalar, kitabxana, auditoriyalar, müəllim və tələbə kompüterləri vahid şəbəkə üzərindən işləməlidir.

Korpus A

Rektorluq, inzibati şöbələr, server otağı və kitabxana.

Korpus B

Fakültələr, müəllim otaqları, kompüter laboratoriyaları.

Korpus C

Tədris auditoriyaları, tələbə laboratoriyaları, konfrans zalı.

Layihə şərti: Korpuslar arasında magistral bağlantı, mərtəbələr üzrə paylayıcı kommutatorlar, VLAN-larla məntiqi seqmentləşdirmə, server və idarəetmə şəbəkəsinin ayrılması, ehtiyat bağlantı və fiziki girişə nəzarət nəzərdə tutulmalıdır. Bu, tədris nümunəsidir; real layihədə kabel məsafələri, bina planı, yanğın normaları və avadanlıq istehsalçısının tələbləri ayrıca yoxlanılır.

Öyrənmə nəticələri

  • Ulduz, şin, halqa, ağac və mesh topologiyalarını qurmaq və müqayisə etmək;
  • fiziki və məntiqi bağlantıların fərqini izah etmək;
  • Ethernet sürətinə və məsafəyə uyğun kabel/standart seçmək;
  • kabel, konnektor, port və avadanlıq nasazlığını diaqnostika etmək;
  • kampus şəbəkəsini təhlükəsizlik və dayanıqlılıq meyarları ilə layihələndirmək.
3.1

Şəbəkə dizaynı və topologiyalar

Şəbəkə topologiyası cihazların fiziki və ya məntiqi əlaqələndirilmə quruluşudur. Fiziki topologiya kabel və qurğuların real yerləşməsini, məntiqi topologiya isə məlumatın şəbəkədə hansı qayda ilə hərəkət etdiyini göstərir. Layihələndirmə zamanı performans, funksionallıq, çeviklik, tutum, əlçatanlıq və miqyaslana bilmə nəzərə alınır.

Fiziki topologiya

Kommutatorların, marşrutlaşdırıcıların, serverlərin, kabel kanallarının və son qurğuların real bağlantısı.

Məntiqi topologiya

VLAN, IP şəbəkələri, marşrutlaşdırma, trafik axını və giriş qaydaları ilə müəyyən edilən əlaqə.

Topologiyaların müqayisəsi

Üç korpuslu kampus üçün tövsiyə olunan hibrid ağac topologiyası

Təhlükəsizlik dizaynı: tələbə, müəllim, inzibati heyət, qonaq Wi‑Fi, server və şəbəkə idarəetməsi üçün ayrıca VLAN/altşəbəkələr; girişlərarası firewall qaydaları; 802.1X imkanları; port security; DHCP snooping və uyğun şəbəkə nəzarətləri nəzərdə tutula bilər. Bu funksiyaların dəstəyi avadanlıq modelindən asılıdır.

Öyrədici topologiya simulyatoru

Topologiya növünü seçin, qovşağa klikləyərək onu söndürün və alternativ yolun olub-olmadığını müşahidə edin.

3.2

Fiziki bağlantı problemlərinin aradan qaldırılması

Fiziki səviyyədə nasazlıq kabelin qırılması, konnektorun düzgün sıxılmaması, portun sıradan çıxması, kabelin həddindən artıq bükülməsi, elektromaqnit maneə, fiber optik ucluğun çirklənməsi və ya enerji təchizatı problemi ilə bağlı ola bilər.

Diaqnostikanın ardıcıllığı

1
Problemi müəyyən edin. Hansı mərtəbə, korpus və istifadəçi qrupu təsirlənib? Tək qurğudur, yoxsa bütöv seqment?
2
Fiziki yoxlama aparın. Link LED, kabel, RJ‑45 konnektor, patch-panel portu, switch portu və enerji təchizatını yoxlayın.
3
Test edin. Kabel testeri ilə naqil düzülüşü və davamlılıq, uyğun halda OTDR ilə fiber xətt yoxlanılır.
4
Nasazlığı lokallaşdırın. Kabeli, patch cord-u və ya portu məlum işlək ehtiyatla dəyişərək səbəbi ayırd edin.
5
Düzəliş və sənədləşdirmə. Düzəlişdən sonra yenidən test edin, port/kabel etiketini və şəbəkə sxemini yeniləyin.
Açıq dövrə (Open)

Naqilin bir damarı qırılıb və elektrik davamlılığı yoxdur. Kabel testeri uyğun damarda əlaqə olmadığını göstərə bilər.

Qısa qapanma (Short)

İki və ya daha çox damar arzuolunmaz şəkildə təmas edir. Testerdə səhv cütlük və ya qısa qapanma siqnalı görünə bilər.

Nasazlıq inyeksiyası simulyatoru

Universitetin B korpusunun 2-ci mərtəbəsində kompüter laboratoriyası internetə çıxmır. Nasazlıq növünü seçin, sonra diaqnostika addımını işə salın.

Nəticə burada görünəcək.
3.3

Ethernet standartları

Ethernet lokal şəbəkələrdə geniş istifadə olunan texnologiyadır. Standartın adı ötürmə sürəti, ötürmə mühiti və məsafə xüsusiyyətləri haqqında məlumat verir. Məsələn, 1000BASE‑T mis burulmuş cüt kabel üzərindən 1 Gbit/s sinfində Ethernet bağlantısını ifadə edir.

100BASE‑TX100 Mbit/sMis burulmuş cütKöhnə son qurğular və xüsusi avadanlıq.
1000BASE‑T1 Gbit/sMis burulmuş cütİstifadəçi portları və mərtəbə bağlantıları.

Kabel seçimi üzrə öyrədici simulyator

Bağlantı növü və məsafəni seçin.
3.4

Naqillərin paylanması texnologiyası

Strukturlaşdırılmış kabel sistemi iş sahəsi rozetkası, üfüqi kabel, telekommunikasiya otağı, patch-panel, magistral kabel və avadanlıq otağından ibarət planlı infrastrukturdur. Kabelin hər iki ucu etiketlənməli, patch-panel və switch portları sənədləşdirilməlidir.

RJ‑45 üçün T568A və T568B rəng ardıcıllığı

T568A (pin 1 → 8)

Yaşıl-ağ · Yaşıl · Narıncı-ağ · Mavi · Mavi-ağ · Narıncı · Qəhvəyi-ağ · Qəhvəyi

T568B (pin 1 → 8)

Narıncı-ağ · Narıncı · Yaşıl-ağ · Mavi · Mavi-ağ · Yaşıl · Qəhvəyi-ağ · Qəhvəyi

Düz kabelin hər iki ucu eyni sxemlə (A–A və ya B–B) sonlandırılır. Krossover kabelin ucları fərqli sxemlə sonlandırıla bilər; müasir avadanlıqlarda Auto MDI‑X dəstəyi səbəbindən çox vaxt ayrıca krossover kabelə ehtiyac olmur.

Naqil ardıcıllığı mini-laboratoriyası

İki ucu seçin. Düz kabel və fərqli sonlandırma fərqini öyrənin.

Avadanlıqların yerləşdirilməsi

Server otağı

Nüvə switch, firewall, serverlər, UPS, rack, girişə nəzarət və soyutma.

Telekommunikasiya otağı

Korpus/mərtəbə paylayıcı switch, patch-panel, kabel meneceri, UPS.

İş sahəsi

İstifadəçi rozetkası, IP telefon, kompüter, printer və Wi‑Fi access point.

Fiziki təhlükəsizlik: server və telekommunikasiya otaqlarına giriş məhdudlaşdırılmalı, rack-lər kilidlənməli, kabel kanalları qorunmalı, ehtiyat enerji və temperatur monitorinqi təmin edilməlidir.

Yoxlama sualları — ssenari əsaslı öyrənmə

Hər sual universitet kampusundan real iş vəziyyətinə əsaslanır. Cavabı seçin və izahı oxuyun. Sualların sonunda ümumi nəticə hesablanır.

3.6

Praktiki tapşırıq

Tapşırıq 1. Şəbəkə topologiyasının dizaynı

Tapşırıq: üç korpuslu universitet üçün miqyaslana bilən, etibarlı və performanslı şəbəkə topologiyası hazırlayın.

Məqsəd: şəbəkə tələblərini, korpusların yerləşməsini, istifadəçi qruplarını və ehtiyat bağlantı ehtiyaclarını nəzərə alaraq infrastruktur layihələndirmək.

Tapşırıq 2. Fiziki bağlantıların sınağı

Hər korpusda bir mərtəbə seçin. Kabel və port etiketləmə planı qurun. Ən azı üç mümkün fiziki nasazlığı (açıq dövrə, qısa qapanma, yanlış patch bağlantısı) müəyyənləşdirin və diaqnostika ardıcıllığını yazın.

Tapşırıq 3. Ethernet və kabel seçimi

İstifadəçi portları, mərtəbə paylayıcıları, server otağı və korpuslararası magistral üçün kabel/media və uyğun Ethernet sinfini əsaslandırın.

Tapşırıq 4. Dayanıqlılıq müqayisəsi

Ulduz, halqa, ağac və mesh modellərində bir bağlantını sıradan çıxarın. Təsirlənən qovşaqların sayını, alternativ yolun olub-olmadığını və bərpa üsulunu müqayisə edin.

LABORATORİYA İŞİ № 3

Kompüter şəbəkəsinin interaktiv layihələndirilməsi və topologiyaların modelləşdirilməsi

İşin adı: Üç korpuslu və üçmərtəbəli universitet binasının kompüter şəbəkəsinin layihələndirilməsi.

İşin məqsədi: Star, Bus, Ring, Tree və Mesh topologiyalarını modelləşdirmək; fiziki və məntiqi bağlantıları qurmaq; Ethernet və kabel növlərini seçmək; şəbəkə qurğularını yerləşdirmək; nasazlıq simulyasiyası aparmaq; etibarlılıq və dayanıqlılığı müqayisə etmək.

Nəzəri hissə

Universitet kampusunda şəbəkə üç iyerarxik səviyyədə planlaşdırılır: nüvə (core), paylayıcı (distribution) və giriş (access). Korpuslararası magistral yüksək tutumlu fiber bağlantılarla, mərtəbə və otaq səviyyəsində bağlantılar isə layihəyə uyğun mis/fiber xətlərlə qurula bilər. Məntiqi seqmentləşdirmə VLAN və IP planı ilə həyata keçirilir.

Praktiki hissə — kampus layihə konstruktoru

Parametrləri seçib kampus planını yaradın.

İşin yerinə yetirilməsi ardıcıllığı

  1. Universitetin üç korpusunun və hər korpusun üç mərtəbəsinin planını çəkin.
  2. Server otağını və əsas nüvə switch-in yerini müəyyən edin.
  3. Hər korpusda paylayıcı, hər mərtəbədə giriş switch-lərini yerləşdirin.
  4. Korpuslararası magistral və ehtiyat bağlantıları seçin.
  5. Son qurğuları ulduz topologiyası ilə mərtəbə switch-lərinə qoşun.
  6. VLAN-ları, IP altşəbəkələri və giriş siyasətlərini planlaşdırın.
  7. Bir kabeli və bir switch portunu sıradan çıxarıb təsiri müşahidə edin.
  8. Nəticələri cədvəldə müqayisə edin və hesabat hazırlayın.

Cisco Packet Tracer və GNS3-də icra

Cisco Packet Tracer

Yeni layihə yaradın; 3 korpus üçün switch/router-ləri yerləşdirin; hər mərtəbənin access switch-lərini əlavə edin; copper/fiber bağlantıları qurun; VLAN və trunk-ları konfiqurasiya edin; Simulation rejimində paket axınını və link kəsilməsini müşahidə edin.

GNS3

Virtual router/switch imkanlarından istifadə edin; topologiyanı qurun; Ethernet linklərini və marşrutlaşdırmanı konfiqurasiya edin; linki söndürüb alternativ marşrutun davranışını yoxlayın. İstifadə edilən switch imicinin L2/VLAN imkanları lisenziya və image-dən asılıdır.

Laboratoriya təhlükəsizliyi: bütün simulyasiyalar lokal və tədris mühitində aparılmalıdır. Universitetin real şəbəkəsində kabel ayırmaq, port söndürmək və ya konfiqurasiya dəyişmək yalnız səlahiyyətli administratorun yazılı icazəsi ilə mümkündür.

Hesabat

Hesabatda məqsəd, kampus planı, topologiya seçiminin əsaslandırılması, avadanlıq siyahısı, kabel/standart seçimi, VLAN və təhlükəsizlik planı, nasazlıq sınaqlarının nəticələri, müqayisə cədvəli və yekun nəticə olmalıdır.
