MODUL 7 — AUTENTİFİKASİYA, AVTORIZASİYA VƏ ŞƏBƏKƏ TƏHLÜKƏSİZLİYİ AUDİTİ

İstifadə: ZIP-i çıxarın və index.html faylını Chrome, Edge və ya Firefox-da açın. Əsas məzmun və simulyasiyalar offline işləyir; rəsmi proqram keçidləri internet tələb edir.

Daxildir:
- AAA, autentifikasiya, parol təhlükəsizliyi, girişə nəzarət və audit üzrə izahlar
- AAA qərar simulyatoru; RADIUS və Kerberos sxemləri
- Autentifikasiya mexanizmi seçimi
- Parol gücü və hesab bloklama siyasəti simulyatoru
- RBAC hüquq matrisi və MAC məxfilik səviyyəsi modeli
- Audit log filtrləmə, şübhəli hadisə təhlili və risk qiymətləndirilməsi
- Audit aləti seçicisi, laboratoriya işi və hesabat strukturu
- 15 suallıq avtomatik qiymətləndirilən test
- Rəsmi proqram və RFC resurslarına keçidlər

Qeyd: Simulyasiyalar offline tədris modelləridir; real server və şəbəkə infrastrukturu deyillər. VirtualBox laboratoriyasında host-only/daxili şəbəkə seçin. Parol simulyatoruna real parol daxil etməyin. Yalnız icazəli sistemlərdə audit aparın.
